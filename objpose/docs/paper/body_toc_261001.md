# INDAI 콜로키움 2026 논문 — 본론·실험 목차 설계 (261001)

## 근거 요약
- INDAI 2024·2025 논문집 64편
  - 장 구성: 서론-본론-결론 3장이 75%, 실험을 별도 장으로 둔 논문 19%, 관련 연구를 별도 장으로 둔 논문 2편.
  - 본론 소제목: 3~5개가 흔하고, 23편(36%)은 소제목이 없음.
  - 평균 분량: 그림 3.5개, 표 1.8개, 참고문헌 6개.
  - 첫 그림: 2025년에는 13/32편이 첫 그림으로 전체 구성도를 둠.
  - 캡션 형식: "그림 n / Fig. n"은 그림 아래, "표 n / Table n"은 표 위.
  - 포스터 수상작 3편: 본론을 2.x 소절 5~6개로 나눠 데이터 → 방법 → 실험 환경 → 결과 순으로 썼고, 결론에 한계와 향후 연구를 둠.
- 비슷한 분야 논문 (SLAM++, Fusion++, FM-Fusion, ConceptGraphs, OpenVox, 국내 짧은 논문 8편)
  - 본론: 개요(구성도) → 인식 모듈 → 데이터 연관·지도 등록 → 지도 갱신 순.
  - 실험: 설정(데이터셋·지표·비교 대상) → 정량 비교 → 실환경·정성 결과 → 속도 순.

(투고 양식 초안의 "Ⅱ. 본론" 번호 중복을 Ⅲ으로 수정)

## Ⅲ. 제안 방법
### 3.1 전체 시스템 구성
- 그림 1: 전체 구조. 입력(RGB-D, LiDAR) → SLAM(ORB-SLAM3 / hdl_graph_slam) ∥ 객체 인식·6D 포즈 추정 → Object Pose Map → 실시간 화면. 기존 모듈은 회색, 제안 모듈은 흰색으로 구분.
- 1문단: 두 흐름이 서로 다른 주기로 동작하고(SLAM 30 Hz, 인식 초당 3~5장), 지도에서 합쳐진다는 점.

### 3.2 객체 인식 및 6D 포즈 추정
- 후보 생성: SAM-6D의 전 영역 분할을 YOLO-World 문구 검출 + MobileSAM 상자 분할로 대체.
- 후보 검증: 의미·외형·색 비교로 비슷한 물체 오인식 제거.
- 포즈 추정과 검증: SAM-6D PEM으로 포즈를 구하고, 실루엣(마스크 IoU) → 특징 일치 → 수렴의 세 조건을 통과한 결과만 지도에 넘김.
- (선택) 그림 2: 한 장면에서 후보 → 검증 → 포즈 결과 예시.

### 3.3 Object Pose Map
- 지도 좌표 등록: 식 (1) T_map_obj = T_map_kf · T_kf_cam · T_cam_obj. 가까운 키프레임 기준으로 저장하여 루프 폐쇄 후 자동 갱신.
- 지연 보상: 결과가 도착한 시점이 아니라 촬영 시점의 SLAM 자세로 등록하고, 화면은 15 Hz로 갱신.
- 객체 상태 갱신: 위치 기반 연관, 상태(후보·확정·놓침·기억), 방향은 다수결로 정하고 신뢰도를 함께 저장.

## Ⅳ. 실험 결과
### 4.1 실험 환경
- 하드웨어: RealSense D455f ×2, VLP-16. 사진은 지면이 부족하면 생략.
- 데이터셋: 공개 데이터셋과 실제 주행.
- 비교 대상: 원본 SAM-6D, FM-Fusion.
- 지표: 지도 등록 수, 중복 객체, 위치·방향 오차, 처리 시간.

### 4.2 객체 지도 비교
- 표 1: 원본 SAM-6D / FM-Fusion / 제안 방법의 등록 수·중복·위치 오차·방향 유무.
- 그림 3: 같은 장면의 지도 비교 이미지.

### 4.3 실시간 동작
- 처리 시간 비교(원본 대 제안). 표 1에 열로 합치거나 표 2로 분리.
- 그림 4: 실제 주행에서 지도의 물체를 영상에 투영한 화면.
