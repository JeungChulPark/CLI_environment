# Ⅲ. 제안 방법 (초안 261001)

## 3.1 전체 시스템 구성

그림 1은 제안하는 시스템의 전체 구조이다. 시스템은 SLAM, 객체 인식 및 6D 포즈 추정, Object Pose Map의 세 부분으로 구성된다. SLAM은 RGB-D 카메라 영상을 입력으로 하는 ORB-SLAM3[1] 또는 LiDAR 점군을 입력으로 하는 hdl_graph_slam[2]을 사용하며, 초당 30회(LiDAR는 10회) 카메라 자세와 키프레임 정보를 출력한다. 객체 인식은 별도의 RGB-D 카메라 영상에서 대상 객체를 찾고 카메라 좌표계 기준의 6D 포즈를 추정한다. 두 부분은 처리 주기가 서로 다르게 독립적으로 동작하며, Object Pose Map에서 객체의 포즈를 지도 좌표계로 변환하여 저장하고 갱신한다. SLAM 알고리즘은 수정하지 않고 출력 자세만 사용하였으므로, 다른 SLAM으로 바꾸어도 나머지 구성은 그대로 사용할 수 있다.

## 3.2 객체 인식 및 6D 포즈 추정

객체 인식은 후보 검출, 후보 검증, 포즈 추정, 포즈 검증의 네 단계로 이루어진다. 대상 객체는 CAD 모델로 주어지며, 실행 전에 각 CAD 모델을 42개 시점에서 렌더링한 템플릿을 만들고 템플릿의 특징을 미리 계산하여 저장해 둔다. 따라서 새로운 객체를 추가할 때 네트워크를 다시 학습할 필요가 없다.

후보 검출 단계에서는 이동 중에도 연속된 영상을 처리할 수 있도록 영상 전체를 분할하지 않고 대상 객체가 있을 만한 영역만 찾는다. 문구 기반 객체 검출기인 YOLO-World[10]에 객체 이름을 입력하여 후보 상자를 얻고, MobileSAM[11]으로 각 상자 안의 마스크를 생성한다. 문구 검출만으로는 모양이 비슷한 다른 물체가 후보에 포함될 수 있으므로, 후보 검증 단계에서 각 후보를 템플릿과 비교한다. DINOv2[12] 특징으로 계산한 의미 유사도와 마스크 내부의 외형 유사도, 그리고 HSV 색 분포의 유사도를 차례로 계산하여 기준값을 넘지 못한 후보는 제거하였다. 하나의 후보가 여러 객체의 기준을 동시에 통과한 경우에는 점수가 가장 높은 객체 하나에만 할당하였다.

포즈 추정 단계에서는 마스크 영역의 깊이 영상으로 관측 점군을 만들고, SAM-6D[4]의 포즈 추정 네트워크를 사용하여 관측 점군과 CAD 모델 점군 사이의 대응으로부터 여러 개의 후보 포즈를 구한다. 후보 포즈에는 형태만 일치하는 잘못된 포즈가 섞여 있을 수 있으므로, 그중 하나를 바로 선택하지 않고 포즈 검증 단계를 거쳐 지도에 전달할 결과를 정하였다. 먼저 후보 포즈로 CAD 모델을 영상에 투영한 실루엣과 관측 마스크의 IoU를 비교하고, 다음으로 관측 점과 대응되는 CAD 모델 점의 특징 유사도를 비교한다. 마지막으로 두 조건을 통과한 후보 포즈의 절반 이상이 하나의 포즈 주변에 모이는 경우에만 최종 결과로 채택하였다. 이 과정에서 형태만 일치하고 180° 뒤집힌 포즈와 같이 잘못된 결과가 제거되며, 검증을 통과하지 못한 결과는 지도에 전달하지 않는다.

## 3.3 Object Pose Map

객체 포즈 추정 결과는 카메라 좌표계 기준이므로 지도에 저장하기 위해서는 영상을 촬영한 순간의 카메라 자세가 필요하다. 객체 인식은 한 장을 처리하는 데 약 0.3초 이상이 걸리므로, 결과가 도착한 시점의 SLAM 자세를 사용하면 그동안 이동한 거리만큼 객체 위치에 오차가 생긴다. 이에 촬영 시각 앞뒤의 SLAM 자세를 보간하여 촬영 순간의 카메라 자세 $T_{MC}(t)$를 구하였다.

또한 SLAM은 루프 폐쇄가 일어나면 과거 키프레임의 자세를 수정하므로, 객체를 지도 좌표계에 고정된 값으로 저장하면 지도 보정 이후 객체와 지도가 어긋난다. 본 논문에서는 각 객체 관측을 촬영 시점과 가장 가까운 키프레임 $K$를 기준으로 식 (1)과 같이 저장하고, 지도에 표시할 때는 식 (2)와 같이 최신 키프레임 자세 $T_{MK}'$을 곱하여 사용하였다.

$$T_{KO} = T_{MK}^{-1}\, T_{MC}(t)\, T_{CO} \tag{1}$$

$$T_{MO} = T_{MK}'\, T_{KO} \tag{2}$$

여기서 $T_{CO}$는 추정된 객체 포즈, $T_{MK}$는 저장 시점의 키프레임 자세이다. LiDAR SLAM을 사용하는 경우에는 LiDAR와 카메라 사이의 외부 파라미터를 곱하여 카메라 자세로 변환하였다. 이를 통해 루프 폐쇄로 키프레임 자세가 수정되면 객체의 위치와 방향도 별도의 처리 없이 함께 갱신된다.

지도에 저장된 객체는 새로운 관측이 들어올 때마다 갱신된다. 같은 종류의 객체가 30 cm 이내에 있으면 같은 객체로 판단하고, 없으면 새로운 후보 객체로 등록한다. 후보 객체는 두 번 이상 관측되고 존재 확률이 기준값을 넘으면 확정 객체로 바뀌어 지도에 표시되며, 시야 안에 있는데도 검출되지 않으면 존재 확률을 낮추어 놓침 또는 기억 상태로 관리하였다. 객체의 위치는 관측값의 누적 평균으로 갱신하였다. 방향은 평균을 사용하면 실제로 관측되지 않은 중간 방향이 만들어질 수 있으므로, 30° 이내로 모이는 관측끼리 묶어 가장 많은 관측을 받은 방향을 사용하였다. 원통형 객체와 같이 회전해도 같은 모양인 객체는 이전 방향과 가장 가까운 대칭 방향으로 맞춘 뒤 갱신하였다.

마지막으로 객체 인식 결과를 기다리는 동안에도 화면에 객체를 표시하기 위해, 지도에 저장된 객체 포즈를 최신 SLAM 자세로 카메라 좌표계에 변환하여 초당 15회 영상 위에 투영하였다. 따라서 인식이 수행되지 않은 프레임이나 객체가 잠시 가려진 프레임에서도 지도에 등록된 객체의 위치와 방향을 확인할 수 있다.
