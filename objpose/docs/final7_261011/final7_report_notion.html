확정 구성 일곱 가지의 실시간 객체 지도 결과

객체 자세 추정 구성 다섯 가지와 FM-Fusion, DualMap 을 직접 수집한 영상 8개와 ObChange SmallRoom 에 실시간으로 돌려 최종 객체 지도를 비교했습니다. 지도 생성 설계는 실행 중에 계산했습니다.

1. 결론

  • ③ 제안 방법 (YOLO-World + MobileSAM + 관문)과 지금 방식의 지도 생성을 쓴 조합이 두 데이터 모두에서 가장 좋았습니다. ObChange SmallRoom 에서 F1 69.6 %(맞음 16/25, 잘못 등록 5), 직접 수집한 영상 8개에서 64/64종 등록에 초과 등록 0개입니다.
  • 물체 판정을 원본 총점에서 제안 관문으로 바꾼 효과가 가장 큽니다. 같은 앞단에서 총점(⑤)은 잘못 등록 15개, 관문(③)은 5개이고 F1은 51.9 → 69.6 % 입니다. 화면 전체 분할에서도 같은 방향입니다(① 48.4 → ② 66.7 %).
  • FM-Fusion 과 DualMap 은 맞은 수는 비슷하지만(각 14, 11/25) 이름이 붙은 잘못된 객체가 203, 115개여서 F1이 11.6, 14.6 % 입니다.
  • 지도 설계(합의로 합치기 등)는 이번 실시간 실행에서 지금 방식을 넘지 못했습니다. 설계 1′은 자세가 정확한 객체(겹침 0.5 이상)를 27 → 48개로 늘렸지만 맞은 수가 78 → 65개로 줄어 F1이 57.8 → 48.1 % 로 내려갔습니다. 어젯밤 사후 계산에서 본 "맞은 수는 그대로"는 다시 나오지 않았습니다.
  • 사진 한 장씩 평가한 10월 8일 실험에서는 순위가 반대였습니다. 총점 판정(⑤)이 제안 관문(③)보다 훨씬 많이 찾았고(YCB-Video 75.7 대 46.1 %) 오답은 같은 수준이었습니다. 제안 관문의 이득은 객체 지도 평가에서만 나타납니다(3절 끝).
  • 반복 실행(6절)에서 관문의 효과는 유지됐습니다. SmallRoom 에서 제안 관문(③, 4회)은 잘못 등록 4~7건, 총점 판정(⑤, 3회)은 15~16건으로 범위가 겹치지 않고, 맞음은 14~16 대 14~15 로 같은 수준입니다.
  • 같은 인식 결과(③)를 여러 지도 생성 방식에 넣어 3회 반복하면(6절), 지금 방식 계열(M1 · M2)이 FM-Fusion · DualMap 의 지도 생성보다 F1 이 높습니다. 합의로 포즈를 정하면(M2) 등록 수는 그대로이고 YCB-Video 위치 오차 중앙값이 6.9~7.5 → 2.9~3.0 mm 로 줄었습니다. 다만 걸러내지 않는 단순 누적(M0)과 F1 은 차이가 없습니다.
  • 1~5절의 수치는 구성마다 한 번 돌린 결과이고, 6절이 3회 반복입니다.
