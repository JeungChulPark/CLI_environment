ObChange에서의 구성별 · 지도 방식별 객체 지도

정답이 있는 ObChange(SmallRoom, 방문 5회)에서 후보 생성 · 마스크 · 특징의 여섯 조합을 돌리고, 같은 기록으로 지도를 지금 방식과 설계 조합 11가지로 만들어 채점했습니다. 직접 수집한 영상에서는 볼 수 없었던 맞음 · 잘못 등록 · 자세 정확도를 정답으로 확인합니다.

1. 요약

질문결과
무엇을 했나ObChange SmallRoom의 방문 5회(정답 물체 25개)에 여섯 구성을 실시간 재생으로 돌리고, 구성마다 같은 기록으로 객체 지도를 12가지 방식으로 만들어 정답으로 채점했습니다.
지도 방식 가운데 F1이 가장 높은 것설계 1 + 3 — 여섯 구성 합계 F1 52.7 % (지금 방식 47.9 %). 맞음 79개, 잘못 등록 71개(지금 방식 78개, 98개).
설계 1′(빼는 규칙 없앰)은 자세를 더 정확하게 만드는가맞은 객체가 정답과 겹치는 비율이 평균 0.499 → 0.571, 겹침 0.5 이상인 객체가 26 → 51개입니다. 맞음은 78 → 78개, 잘못 등록은 98 → 98개입니다.
설계 2(깊이로 확인하고 다듬기)지금 방식에 설계 2만 더하면 F1 47.9 → 44.3 %, 겹침 평균 0.499 → 0.518. 설계 1′ 뒤에 더하면 47.9 → 46.9 %, 겹침 0.571 → 0.570입니다.
설계 3(약한 증거 누적)지금 방식에 설계 3만 더하면 F1 47.9 → 47.2 %, 맞음 78 → 77개, 잘못 등록 98 → 99개입니다.
여섯 구성 가운데지금 방식 기준으로 F1이 가장 높은 것은 5. YOLO-World + MobileSAM + ViT-L(56.6 %)입니다.

2. 실험 조건

데이터
ObChange SmallRoom. 방마다 정답이 있는 방문 5회, 채점 대상 정답 물체 25개(YCB-V와 겹치는 11종). 모든 방문에서 11종 전부를 찾게 했습니다.
실시간 조건
영상이 10 fps로 도착한다고 보고, 앞 프레임의 처리가 끝난 순간 도착해 있는 최신 프레임 하나만 처리합니다. 카메라 자세는 데이터셋 제공값입니다.
구성
실제 환경 실험과 같은 인식기 여섯 가지. 후보 생성 · 마스크 · 특징만 다르고, 물체 판정은 원본 SAM-6D 점수(기준 0.5), 자세 추정과 자세 검증은 항상 켰습니다. 3 · 4번은 YOLO-World 상자마다 가장 잘 겹치는 FastSAM-x 마스크 하나를 씁니다.
지도 방식
지금 방식(같은 이름 30 cm 묶기, 위치 평균 · 방향 다수결, 존재 확률, 깊이 검사)과 설계 조합 11가지. 설계의 내용과 기준값은 실제 환경 실험과 같고, ObChange에 맞춰 조정하지 않았습니다. 조합은 1 → 2 → 3 순서로 적용합니다.
채점
카메라가 실제로 본 점을 지도 객체에 배정(2 cm)하고, 정답 물체와 같은 이름의 객체가 0.25 이상 겹치면 맞음(TP)입니다. 이름이 붙었는데 맞음이 아닌 객체는 잘못 등록(FP), 맞는 객체가 없는 정답은 놓침(FN)입니다. 겹침 평균은 맞은 객체가 정답과 겹치는 비율의 평균으로, 자세가 정확할수록 큽니다.
반복
한 번씩 돌렸습니다.
설계하는 일
설계 1객체마다 묶인 관측 가운데 서로 가까운(25 mm, 20°) 자세의 가장 큰 무리로 자세를 정합니다. 무리가 관측 3개 미만이거나 가중치의 30 % 미만이면 객체를 뺍니다.
설계 1′설계 1에서 객체를 빼는 규칙만 없앤 것
설계 2CAD를 주변 깊이 점에 다시 맞추고(6 cm, 20° 안), 깊이 지지율이 0.2 미만이면 객체를 뺍니다.
설계 3검증에서 떨어진 후보도 증거로 쌓아, 증거 6개 이상이고 지지율 0.5 이상인 미등록 무리를 등록하고, 10 cm 안에 이름이 다른 객체가 둘이면 증거가 많은 쪽만 남깁니다.

5. 읽는 법

  • 설계 1의 빼는 규칙. 설계 1은 F1 48.1 %, 설계 1′은 47.9 %입니다(지금 방식 47.9 %). 맞음은 설계 1 71개, 설계 1′ 78개, 잘못 등록은 74개와 98개입니다.
  • 자세의 정확도. 맞은 객체의 겹침 평균은 지금 방식 0.499, 설계 1′ 0.571, 설계 2 0.518, 설계 1′ + 2 0.570입니다. 직접 수집한 영상에서는 깊이 지지율로만 볼 수 있었던 것을 여기서는 정답과의 겹침으로 본 것입니다.
  • 설계 3. 지금 방식에 더했을 때 F1 변화는 -0.6 %p, 설계 1′ + 2에 더했을 때는 +4.3 %p입니다. 직접 수집한 영상에서는 초과 등록만 늘렸는데, 물체 종류가 섞여 있고 잘못 등록이 많은 이 데이터에서는 한 자리의 이름 충돌을 정리하는 부분이 작동합니다.
  • 직접 수집한 영상의 결과와 다른 점은 그대로 적어 두었습니다. 두 데이터에서 같은 방향인 것만 믿을 만한 결론입니다.
  • 기준값은 직접 수집한 영상 하나를 보고 정한 것을 그대로 썼습니다. 한 번씩 돌린 결과이고, 정답 물체 수가 적어 물체 한두 개에 F1이 몇 %p 움직입니다.
