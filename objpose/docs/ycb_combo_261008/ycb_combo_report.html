YCB-Video · YCB-M 조합 실험 결과

원본 SAM-6D와 제안 방법을 이루는 부품을 가능한 모든 조합으로 바꿔 가며 같은 이미지에서 돌렸습니다. 구성 21개를 두 데이터셋, 두 질의 조건에서 한 번씩, 모두 84회입니다. YCB-Video는 BOP19 목록 900장 중 4장마다 1장(225장, 정답 물체 1028개), YCB-M은 32장면에서 32장마다 1장(232장, 정답 물체 1180개)을 썼습니다.

1. 요약

질문결과
자세 검증은 효과가 있는가있습니다. 검증만 켠 짝 10쌍의 평균 오답이 줄었습니다. 아는 조건: YCB-Video 0.185 → 0.040, YCB-M 0.482 → 0.124 / 모르는 조건: YCB-Video 1.591 → 0.423, YCB-M 1.416 → 0.333. 대가는 찾은 비율(아는 조건: YCB-Video -6.3%p, YCB-M -8.5%p / 모르는 조건: YCB-Video -6.4%p, YCB-M -8.3%p)과 장당 약 370~440 ms입니다.
YOLO-World 문구 상자로 후보를 만드는 것은 효과가 있는가판정을 원본 점수 0.5로 같게 두면, 화면 전체 분할(FastSAM-x)과 비교해 찾은 비율은 조금 낮고(아는 조건: YCB-Video -3.3%p, YCB-M -8.1%p / 모르는 조건: YCB-Video -0.8%p, YCB-M -2.9%p) 장당 시간은 짧습니다(아는 조건: YCB-Video 719 → 464 ms, YCB-M 792 → 457 ms / 모르는 조건: YCB-Video 798 → 574 ms, YCB-M 835 → 540 ms). 물체를 모르는 조건에서는 오답도 적습니다(아는 조건: YCB-Video 0.105 → 0.061, YCB-M 0.313 → 0.247 / 모르는 조건: YCB-Video 0.967 → 0.480, YCB-M 0.773 → 0.589).

FastSAM 상자에서 MobileSAM으로 마스크를 다시 만들면찾은 비율 차이는 2%p 안입니다(아는 조건: YCB-Video -0.9%p, YCB-M +1.6%p / 모르는 조건: YCB-Video -0.1%p, YCB-M +1.4%p). 장당 70~90 ms가 더 듭니다.
물체를 모르는 조건(21종 질의)이 되면손대지 않은 원본 SAM-6D의 오답이 YCB-Video 0.284 → 6.373/장, YCB-M 0.750 → 5.056/장으로 늘어납니다. 대부분 사진에 없는 물체에 답한 것입니다(YCB-Video 6.00/장). 다른 구성도 모두 오답이 늘고, 순위가 일부 바뀝니다.
  • 물체를 모르는 조건의 YCB-Video에서, 자세 검증을 켠 ViT-S 구성끼리 비교하면: 화면 전체 분할 + 원본 판정 76.2% · 오답 0.556/장 · 832 ms, YOLO-World 상자 + 원본 판정 75.5% · 오답 0.320/장 · 689 ms, YOLO-World 상자 + 제안 관문(배포) 47.2% · 오답 0.293/장 · 581 ms, YOLO-World 상자 + 제안 관문(완화) 59.8% · 오답 0.573/장 · 983 ms.
  • 같은 비교를 YCB-M에서 하면: 화면 전체 분할 + 원본 판정 63.0% · 오답 0.341/장 · 790 ms, YOLO-World 상자 + 원본 판정 61.5% · 오답 0.345/장 · 649 ms, 제안 관문(배포) 42.6% · 오답 0.297/장 · 524 ms, 제안 관문(완화) 54.8% · 오답 0.534/장 · 928 ms.
  • 결론에 중요한 일곱 구성은 YCB-Video 900장과 YCB-M 925장 전체로도 돌렸고, 표본 결과와 같은 방향이었습니다(8절).
  • 찾을 물체 목록을 장면 물체만, 10개, 15개, 20개, 21개로 바꿔 본 결과는 7절에 있습니다. 오답은 목록 길이에 거의 비례해 늘고, 원본 SAM-6D의 기울기가 검증을 켠 구성의 10배 이상입니다.
  • 제안 관문의 배포 설정과 완화 설정을 가르는 네 가지를 하나씩 바꾼 결과는 6절에 있습니다. 찾은 비율을 올리는 것은 주로 문구 교체와 배정 대안이고, 오답을 늘리는 것은 배정 대안입니다.
  • 즉 제안 방법의 세 부품 가운데 자세 검증과 YOLO-World 후보 생성은 수치로 뒷받침되고, 관문·상자 배정은 두 데이터셋 모두에서 찾은 비율을 깎았습니다.

2. 실험 조건

물체를 아는 조건과 모르는 조건

인식기는 찾을 물체의 목록을 받아야 동작합니다. 두 조건은 이 목록을 무엇으로 주느냐만 다릅니다. 이미지, 정답, 채점 방식은 같습니다.

예시: YCB-Video 48번 영상의 1번 사진

이 사진에는 물체 5개가 찍혀 있습니다: 커피 캔, 참치 캔, 머그, 대형 집게, 특대 집게.

  • 물체를 아는 조건. 인식기에 "커피 캔, 참치 캔, 머그, 대형 집게, 특대 집게를 찾아라"라고 시킵니다. 가위는 목록에 없으므로 인식기가 가위라고 답할 방법이 없습니다.
  • 물체를 모르는 조건. 인식기에 "21종 가운데 있는 것을 찾아라"라고 시킵니다. 16종은 이 사진에 없습니다. 그 16종 가운데 하나에라도 답하면 오답입니다.
  • 실제 결과. 이 사진에서 원본 SAM-6D는 물체를 모르는 조건일 때 5개 외에 가위, 폼 블록에도 답했습니다. 사진에 없는 물체입니다.

두 조건의 수치를 읽는 법

  • 찾은 비율은 두 조건 모두 사진에 실제로 있는 물체만 분모로 씁니다. 그래서 두 조건의 값을 그대로 비교할 수 있습니다.
  • 오답 / 장은 물체를 모르는 조건에서 "없는 물체에 답한 것"이 더해집니다. 원본 SAM-6D는 900장 기준 0.291 → 6.371/장이 되고, 그중 5.99개가 없는 물체에 답한 것입니다.
  • 물체를 아는 조건은 있는 물체의 자세를 얼마나 잘 맞히는가를 봅니다. 물체를 모르는 조건은 거기에 더해 없는 물체를 없다고 할 수 있는가를 봅니다.
  • 찾을 물체가 늘면 처리 시간도 늘어납니다. 자세 추정을 돌리는 물체 수가 늘기 때문입니다.

3. 핵심 구성 다섯 가지와 선택 이유

조합 21가지 가운데 다섯 구성을 골라 전체 이미지 실행(8절)과 목록 크기 실험에 썼습니다. 고른 기준은 하나입니다. 두 구성을 나란히 놓았을 때 한 가지만 다르도록 해서, 차이가 어느 부품에서 오는지 말할 수 있게 하는 것입니다. 검증의 효과를 따로 보려고 두 구성에는 검증만 끈 짝을 붙였습니다. 그래서 실행은 일곱 가지입니다.

9. 해석

  • 자세 검증. 후보 생성, 마스크, 특징, 판정이 무엇이든 검증을 켜면 오답이 줄었습니다. 검증만 다른 40쌍(데이터셋 2 × 조건 2 × 구성 10쌍) 모두에서 오답이 줄었습니다. 물체를 모르는 조건에서 효과가 더 큽니다.
  • YOLO-World 후보 생성. 판정을 같게 두면 화면 전체 분할과 찾은 비율 차이가 YCB-Video에서 1~3%p입니다. 후보 수가 적어 특징 계산이 짧고, 물체를 모르는 조건에서는 오답이 적습니다. YCB-M에서는 차이가 더 벌어집니다(8.1%p).
  • 제안 관문과 상자 배정. 찾은 비율 손실의 대부분이 여기서 나옵니다. 문구를 같게 맞추고 판정만 바꾼 비교(배포 관문 + 새 문구 대 원본 판정)에서 찾은 비율은 YCB-Video 앎 67.1 대 79.0%, YCB-Video 모름 48.7 대 75.5%, YCB-M 앎 51.4 대 60.0%, YCB-M 모름 46.1 대 61.5%입니다. 배포 설정 그대로와의 차이(YCB-Video 19~30%p, YCB-M 16~19%p)에는 문구의 효과(+1.5~+7.7%p)가 섞여 있습니다. 오답은 조건에 따라 조금 줄거나 늘어 일정한 방향이 없었습니다.
  • ViT-L. 물체를 아는 조건에서는 이득이 없고 시간만 두 배입니다. 물체를 모르는 조건에서는 오답을 줄입니다.
  • FastSAM-s. 두 데이터셋 모두에서 5~6%p 덜 찾고 빨라지지도 않았습니다. 이 장비에서는 쓸 이유가 보이지 않습니다.
  • 속도. 검증을 켠 구성 가운데 가장 빠른 것은 YOLO-World 상자 + 제안 관문(배포)입니다(YCB-Video 491 ms). 답하는 물체가 적은 것이 이유의 일부입니다. YOLO-World 상자 + 원본 판정 + ViT-S는 610 ms, 화면 전체 분할 + ViT-S는 659 ms입니다.

10. 한계

  • 구성마다 1회 실행입니다. 반복 측정에 따른 흔들림은 재지 않았습니다.
  • 조합 표와 설정을 하나씩 바꾼 표는 4분의 1 표본입니다. 정답 물체가 1028개, 1180개라서 찾은 비율의 1~2%p 차이는 구분되지 않습니다.
  • 원본 점수의 기준은 0.5 하나만 썼습니다(기준선은 0.2). 기준을 바꾸면 찾은 비율과 오답이 함께 움직입니다.
  • 제안 관문의 기준값은 실제 주행용 물체에 맞춘 값과 YCB-Video 검증 프레임에서 고른 값입니다. YCB-M에 따로 맞추지 않았습니다. 문구도 같습니다.
  • 실시간 지도 실험과 실제 주행 영상은 이 보고서에 없습니다. 한 장씩 따로 평가한 결과입니다.
  • 장당 시간은 이 장비의 값입니다. 다른 GPU에서는 구성 간 순서가 달라질 수 있습니다.
