객체 지도 실험 종합: 어떤 조합이 가장 좋은가

데이터셋 두 가지(ObChange SmallRoom, 직접 수집한 영상 8개), 객체 자세 추정 구성 여섯 가지, 객체 지도 생성 방식 열두 가지를 모두 조합해 실시간 조건으로 돌린 결과를 한데 모았습니다. 조합마다의 수치와 최종 객체 지도를 보이고, 가장 좋은 조합을 고른 근거를 적었습니다.

1. 결론

항목결론과 근거
가장 좋은 조합6. YOLO-World + MobileSAM + ViT-S + 설계 1′ (빼는 규칙 없앰). ObChange에서 F1 54.5 %(맞음 15/25, 잘못 등록 15), 직접 수집한 영상에서 64/64종 등록 · 초과 등록 5개입니다.
지도 생성 방식: 설계 1′ (빼는 규칙 없앰)두 데이터 어디에서도 지금 방식보다 나빠지지 않으면서 자세를 가장 정확하게 만든 방식입니다. ObChange에서 맞음 78 → 78, 잘못 등록 98 → 98, 정답과 0.5 이상 겹치는 객체 26 → 51개, 겹침 평균 0.499 → 0.571. 직접 수집한 영상에서 등록된 종류 364 → 364, 초과 등록 16 → 16, 깊이 지지율 0.84 → 0.86.
자세 추정 구성: 6. YOLO-World + MobileSAM + ViT-S직접 수집한 영상에서 물건을 놓치지 않는 구성(2, 4, 6번) 가운데 ObChange F1이 가장 높습니다. ObChange F1 순서는 6번 54.5 > 4번 49.1 > 5번 49.1 > 1번 48.0 > 2번 44.4 > 3번 42.3입니다(설계 1′ (빼는 규칙 없앰) 기준).
ObChange F1만 보면지도 방식 가운데 F1이 가장 높은 것은 설계 1 + 3(52.7 %, 지금 방식 47.9 %)입니다. 그러나 직접 수집한 영상에서 등록된 종류 364 → 335, 초과 등록 16 → 28로 지금 방식보다 나빠지는 면이 있어 고르지 않았습니다.
믿을 수 있는 정도모든 실행은 한 번씩입니다. ObChange는 구성당 정답 물체가 25개라 물체 하나에 F1이 약 4 %p 움직이고, 직접 수집한 영상은 정답 자세가 없습니다. 두 데이터에서 같은 방향으로 나온 것(설계 1′의 자세 개선)은 믿을 만하고, 구성 사이의 몇 %p 차이는 반복 실행으로 확인해야 합니다.

2. 무엇을 비교했나

세 가지를 바꿔 가며 모든 조합을 돌렸습니다. 데이터셋 두 가지, 객체 자세 추정 구성 여섯 가지, 객체 지도 생성 방식 열두 가지입니다. 모든 실행은 영상이 원래 속도로 들어오고 처리가 밀리면 최신 프레임만 쓰는 실시간 조건입니다.

5. 왜 이 조합인가

단계 1. 지도 생성 방식 고르기

  • 설계 3은 ObChange에서 지금 방식에 더하면 F1 -0.6 %p, 설계 1′에 더하면 +3.2 %p입니다. 직접 수집한 영상에서는 초과 등록을 16 → 30개로 늘립니다. 데이터에 따라 방향이 갈립니다.

8. 한계와 다음에 할 일

  • 모든 실행이 한 번씩입니다. 실시간 조건에서는 실행마다 처리되는 프레임이 달라지므로, 구성 사이의 몇 %p 차이는 반복 실행으로 확인해야 합니다.
  • ObChange의 정답 물체는 구성당 25개이고, 카메라 자세가 로봇이 스스로 추정한 값이라 수 cm의 오차가 있습니다. 겹침 비율이 전체적으로 낮게 나옵니다.
  • 직접 수집한 영상은 정답 자세가 없습니다. 등록된 종류와 초과 등록은 이름과 개수만 본 것이고, 깊이 지지율은 그 자리에 그 모양의 표면이 있는지만 봅니다.
  • 물체 판정은 여섯 구성 모두 원본 SAM-6D 점수 방식입니다. 제안 관문을 쓰는 구성(7 · 8번)은 아직 돌고 있어 이 표에 없습니다. ViT-L의 판정 기준(0.5)은 ViT-S에 맞춘 값을 그대로 썼습니다.
  • 설계 1~3의 기준값은 직접 수집한 영상 하나를 보고 정했고 ObChange에 맞춰 조정하지 않았습니다. 설계 3은 두 데이터에서 방향이 갈리므로 기준을 다시 잡아야 합니다.
  • 다음에 할 일: 고른 조합을 세 번 이상 반복해 차이가 유지되는지 확인, 설계 3의 이름 충돌 정리 부분만 따로 떼어 평가, ViT-L용 판정 기준 재설정.
