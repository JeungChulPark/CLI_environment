# 17. 논문 비교표 설계 — SAM-6D 원논문의 비교 방식과 개선안 3 이 내세울 것 (2026-10-08)

> 개선안 3(원본 앞단 + 자세 검증, + 군집 먼저)을 주 내용으로 논문을 쓸 때의 표 설계입니다. 1절은 SAM-6D 원논문(arXiv 2311.15707v2)이 다른 논문과 어떻게 비교했는지, 2절은 우리가 그 틀을 어디까지 따르고 어디서 갈라서야 하는지, 3절은 실제 수치로 채운 논문용 표 7개입니다. 수치 출처는 16 문서(900장, RTX 4090), 15 문서(실시간 3회 반복), 14 문서 §10~11(논리), 02 문서(공개 수치)이고, BOP AR 은 2026-10-08 공식 bop_toolkit 으로 새로 채점했습니다(`src/ycbv/out_4090/bop/eval/`).

## 1. SAM-6D 원논문은 어떻게 비교했나

### 1.1 평가 틀

| 항목 | SAM-6D 가 쓴 방식 |
|---|---|
| 데이터 | BOP 핵심 7개(LM-O, T-LESS, TUD-L, IC-BIN, ITODD, HB, YCB-V). 표마다 7개 열 + 평균 열 |
| 인식(분할) 지표 | AP — IoU 0.50~0.95 를 0.05 간격으로 평균한 mAP |
| 자세 지표 | AR — VSD·MSSD·MSPD 세 오차의 재현율 평균(BOP 공식) |
| 비교 대상 | 분할: ZeroPose, CNOS(FastSAM/SAM). 자세: MegaPose, ZeroPose, GigaPose(정제 유무 † 로 표시, 리더보드 값 ∗ 표시) |
| 조건 통일 | 자세 표를 "지도 학습 마스크(MaskRCNN)" 와 "제로샷 마스크" 두 부분으로 나누고, 같은 마스크를 쓴 행끼리 비교 |
| 절제 실험 | 점수 항(의미·외형·기하) 넣고 빼기(표 1 안에 포함), 배경 토큰 대 최적 수송(AR 81.4 → 84.5, 4.31 → 1.36 s), 거친+미세 두 단계(77.6 / 40.2 / 84.5), 미세 단계 트랜스포머 종류(81.7 / 78.4 / 84.5) |
| 시간 | 장당 평균 시간을 **단계별**(분할 / 자세 / 전체)로, GPU 명시(RTX 3090): FastSAM 0.45 + 0.98 = 1.43 s, SAM 2.80 + 1.57 = 4.37 s |
| 논조 | "outperforms existing methods", "without re-training or finetuning", "without the time-intensive render-based refiner" — 더 높은 AR 과 더 적은 비용을 함께 말함 |

### 1.2 YCB-V 에서 SAM-6D 가 보고한 값 (우리 표의 기준점)

| 지표 | 값 | 출처 |
|---|---|---|
| 분할 AP (FastSAM / SAM) | 62.1 / 60.5 | Table 1 |
| 자세 AR (FastSAM / SAM, 정제 없음) | 83.4 / 84.5 | Table 2 |
| 장당 시간 (FastSAM / SAM, RTX 3090) | 1.43 / 4.37 s | Table 6 |
| 우리 4090 재실행 원본 L0 (FastSAM-x, ViT-L, 판정 0.2) | AR **82.8**, 530 ms | `out_4090/bop/eval/ladderL0` |

- 재실행 82.8 은 논문 83.4 와 0.6 차이라 "재현됨" 으로 적을 수 있습니다. 02 문서에 적힌 78.7 은 노트북 초기 실행이라 이제 쓰지 않습니다.

### 1.3 이 틀에서 바로 가져올 것과 못 가져올 것

- **가져올 것:** YCB-V 에서 AR 과 장당 시간을 같은 GPU 에서 보고, 단계별 시간 표, "같은 입력·같은 모델에서 단계만 바꿈" 식의 절제 실험, 정제 유무처럼 **조건 표시(답하지 않음 가능 여부)** 를 열로 두는 방식.
- **못 가져올 것:** 7개 데이터셋 전체(우리는 YCB-V 만 실행), 분할 AP(우리는 분할 단계를 바꾸지 않음), 그리고 **"AR 이 더 높다" 는 주장.** 검증은 답을 빼는 단계라 AR 은 반드시 내려갑니다(82.8 → 74.1). 이 표를 주 표로 세우면 심사에서 집니다.

## 2. 우리가 내세울 것 — 자세 추정 논문이 아니라는 점

### 2.1 질문이 다르다

| | SAM-6D 류 (벤치마크 자세 추정) | 우리 (객체 지도용 인식) |
|---|---|---|
| 묻는 것 | 물체마다 얼마나 정확한 자세를 내나 (AR) | 지도에 틀린 물체를 남기지 않으면서 쓸 만한 재현율과 실시간 처리율을 유지하나 |
| 출력 | 물체마다 **반드시** 답 하나 (장면에 없어도 1위를 냄) | 통과 가설이 없으면 **답하지 않음**(abstention) |
| 오답 비용 | 없음 (재현율 지표만) | 큼 — 틀린 항목은 지도에 남아 계획을 망침 |
| 시간 | 장당 1.4~4.4 s 도 허용 | 영상 처리율(Hz)·지도 올라가는 시간 |
| 평가 단위 | 한 장 | 한 장 + 영상 끝 지도 상태(맞음/잘못/못 찾음) |

### 2.2 내세울 점 네 가지 (모두 수치 있음)

1. **가설 집합 검증과 기권.** PEM 가설 300개를 기하 1위로 뭉개지 않고 윤곽·무늬·합의로 채택 여부를 정한다. 학습 없음, 가중치 변경 없음, 입력은 원본과 같음(CAD 만). 900장: 오답/장 0.308 → 0.051(1/6), 정답 비율 93.2 → 98.6%.
2. **같은 물체끼리는 자세가 더 정확하다.** 두 방법이 모두 답한 3,378개에서 ADD-S AUC 94.6 → 96.7, 오차 중앙값 1.79 → 1.73 mm. "답을 빼서 정밀도를 산 것" 이 아니라 "남긴 답도 더 좋다" 는 근거.
3. **군집 먼저 검증으로 비용을 줄여 실시간에 들어간다.** 답 99% 동일, 장당 342 → 240 ms(원본 530 의 45%), 실시간 처리율 2배(260901 3.63 → 7.54 Hz, YCB-V 1.76 → 3.14 Hz).
4. **지도 결과가 안정적이다.** 실제 영상 260901 3회 모두 최종 지도 8/0, 원본은 6/3·6/3·8/1.

### 2.3 미리 인정할 것 (표에 함께 둔다)

- 찾은 비율 92.4 → 80.9%(−11.5%p), BOP AR 82.8 → 74.1. 둘 다 재현율 지표라 기권의 직접 비용이다. 검증이 버린 414개 중 249개는 맞는 답이었다(16 문서).
- YCB-V 실시간에서 원본 대비 잘못 항목 차이는 작다(3회 평균 46.7 → 43.7, 폭 겹침). 오답 억제 근거는 검증 켬/끔 대조(173 → 36~47)와 900장, 실제 영상에서 가져온다.
- 속도 이득의 절반은 ViT-L → ViT-S 교체(개선안 2 단계, 181 → 29 ms)에서 온다. 검증 자체는 비용이고, 군집 먼저는 그 비용을 줄인 것이다.

### 2.4 한 줄 자리 잡기

> "자세 추정기를 바꾸는 논문이 아니다. 자세 추정기(SAM-6D) 위에 **답할지 말지를 결정하는 검증 단계** 를 더해, 재현율 일부를 내주고 객체 지도의 오답을 없애며, 군집 먼저로 그 검증을 실시간 예산 안에 넣는 논문이다."

### 표 4c. 합의 문턱 운영 곡선 — 기권의 비용을 조절하는 손잡이 (900장, 2026-10-08 추가)

그래서 합의 문턱(`verify.cluster_min_occupancy`)만 0.30 → 0.20 → 0.15 로 낮춰 900장을 다시 돌렸습니다(개선안 3 + 군집 먼저, 나머지 설정 동일, `results_occ_study_4090.json`, `same_object_occ_study_4090.json`).

|---|---|---|---|---|---|---|---|---|

- 기록된 점수로 추정하면 0.15 아래에서는 회복이 거의 없고(0.10 에서 +4개) 오답만 늘 수 있어 더 내리지 않는다.
- **논문 쓰임 (2026-10-08 결정: 기본 운영점은 0.30 유지):** 우리 논문의 핵심 지표는 오답/장이므로 0.15 로 내려 정답 비율 3.4%p 를 얻는 대신 오답을 0.051 → 0.063 으로 늘리는 선택은 하지 않는다. 세 점은 "재현율–오답 운영 곡선" 그림 한 장으로 두고 "문턱 하나로 찾는 수와 오답을 맞바꿀 수 있고, 우리는 오답 쪽을 택했다"는 설명 재료로 쓴다. 어느 점에서도 정밀도 98% 이상, 오답/장은 원본의 1/5 이하.

- **윤곽·질감 문턱 곡선(2026-10-08, 18 문서 B 절):** 나머지 두 관문도 4점씩 흔든 결과 정답 비율 98.4~99.0%, 오답/장 0.034~0.063 으로 어느 설정에서도 원본과 멀다. 질감 문턱이 가장 민감(0.42 → 0.50: 찾은 비율 81.3 → 76.6%, 오답 55 → 31개). 세 곡선을 한 그림으로.
