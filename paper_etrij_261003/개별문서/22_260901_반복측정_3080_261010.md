# 22. 실 데이터 반복 측정 — 260901, 원본 0.5 대 개선안 3 + 군집 먼저, RTX 3080 Ti Laptop (2026-10-10)

> 15 문서 §4-3(RTX 4090)과 같은 실험을 노트북에서 다시 했습니다. Mac ORB-SLAM3(특징점 2000) + 이 노트북(RTX 3080 Ti Laptop)으로 녹화 260901_cbnu_bigeightcircle(314초, 선반 두 개, 물체 8개)을 1배속 실시간 재생했습니다. 확인용이며 최종 수치는 RTX 5090 에서 냅니다. 스크립트 `src/realdata/run_real_repeat_3080.sh`(+ `_redo.sh`), 결과 `src/realdata/results_real5_repeats_3080.json`.

## 0. 요약

- **개선안 3 + 군집 먼저는 세 번 모두 8 / 0** 입니다(최종 지도 맞음 / 잘못). 원본 0.5 는 7/2, 6/3, 6/3 이고 공룡 인형·사프란을 놓쳤습니다. 4090 과 같은 결과입니다(4090: 8/0 ×3 대 6/3, 6/3, 8/1).
- **인식 빈도:** 원본 0.87 Hz, 개선안 3.48 Hz 로 **4.0배**입니다(4090 은 3.63 대 7.54 Hz, 2.1배). 원본의 ViT-L 특징 단계가 노트북 GPU 에서 더 무겁기 때문입니다.
- 개선안 3 의 2회차는 ORB-SLAM3 가 **3.10 m 짜리 잘못된 루프 보정**을 넣어(다른 회 7~26 cm) 지도 전체가 틀어졌습니다. 4090 때와 같은 규칙으로 버리고 다시 돌렸습니다(아래 2절).

## 3. 4090 과의 비교 (같은 녹화, 같은 설정)

| 항목 | 원본 0.5 (3080 / 4090) | 개선안 3 + 군집 먼저 (3080 / 4090) |
|---|---|---|
| 인식 빈도 | 0.87 / 3.63 Hz | 3.48 / 7.54 Hz |
| 최종 지도 맞음 / 잘못 (3회 평균) | 6.3 / 2.7  ·  6.7 / 2.3 | **8.0 / 0.0  ·  8.0 / 0.0** |
| 점수 끝 / 평균 | 59.7 / 53.6%  ·  66.0 / 55.7% | 100 / 78.4%  ·  100 / 78.9% |
| 개선안 / 원본 인식 빈도 | 4.0배 (3080) | 2.1배 (4090) |

- **정확도는 GPU 와 관계없이 재현됩니다.** 개선안 3 + 군집 먼저는 두 GPU 에서 6번 모두 8 / 0, 평균 점수 78.4 대 78.9% 입니다.
- **속도 이득은 작은 GPU 에서 더 큽니다.** 개선안 3 은 노트북에서도 3.5 Hz 를 유지하지만, 원본은 ViT-L 특징 단계 때문에 0.9 Hz 로 떨어집니다. 18 문서 E 절(RTX PRO 6000 에서 2.7배)과 반대 방향이 아니라, "원본의 무거운 특징 단계가 GPU 에 민감하다"는 같은 이유입니다.
- 원본의 실행 간 흔들림은 노트북에서 작아졌습니다(4090 은 6/3, 6/3, 8/1, 노트북은 7/2, 6/3, 6/3). 인식 빈도가 낮아 처리하는 프레임이 적고, 공룡 인형은 세 번 모두 놓쳤습니다.

## 4. 논문에서의 쓰임
- 원고 표 6(실시간 객체 지도)의 260901 행은 4090 수치를 유지하고, "노트북 GPU(RTX 3080 Ti Laptop)에서도 개선안 3 + 군집 먼저는 3회 모두 8 / 0, 인식 3.5 Hz(원본 0.9 Hz)"를 본문이나 각주로 덧붙일 수 있습니다. 녹화 실행(7.1·7.2절)의 인식 장치가 이 노트북이라 실제 운용 조건을 보여 주는 의미가 있습니다.
- 잘못된 루프 보정 사례(3.10 m)는 7.5절 한계의 근거로 함께 적을 수 있습니다(40회 중 2회에 이어 노트북 6+1회 중 1회).
