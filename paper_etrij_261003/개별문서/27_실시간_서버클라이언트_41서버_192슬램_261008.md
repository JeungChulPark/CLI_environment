### 4.1 만든 것

- ORB-SLAM3 호스트 `.41:~/objpose` — 저장소의 `objpose/linux_slam/build_host.sh` 로 빌드(패치 2개 적용, -march=native, 48코어 약 10분). Pangolin 소스와 ORB 어휘 파일은 .192 의 `~/objpose` 에서 복사했습니다.
- .41 에는 sudo 가 없어 `libsqlite3-dev`·`nlohmann-json3-dev` 를 apt 로 못 깝니다. .192 의 `/usr/include/sqlite3*.h`, `/usr/include/nlohmann/` 을 `deps/install/include/` 에 두고, `deps/install/lib/libsqlite3.so` 는 시스템 `libsqlite3.so.0` 링크, `lib/cmake/nlohmann_json/nlohmann_jsonConfig.cmake` 는 헤더 전용 INTERFACE 타깃으로 손으로 썼습니다. `build_host.sh` 가 이 상태면 apt 를 건너뛰고 `CMAKE_PREFIX_PATH=deps/install` 로 찾도록 고쳤습니다(커밋 32dbc801).
- hub 는 SLAM 을 `ssh -R` 역터널로 띄우므로 자기 자신에 키 로그인만 열면(`~/.ssh/id_ed25519.pub` → `authorized_keys`, `known_hosts` 에 localhost) 코드 수정 없이 `--mac-host localhost --mac-runner ~/objpose/run_slam.sh --mac-slam-session ~/DeepLearning/Dataset/data_slam_converted/<녹화>/SLAM` 으로 됩니다. 녹화 원본(SLAM db3)은 .41 의 /mnt/nvme1 에 5개 모두 있어 NAS 가 필요 없습니다.
