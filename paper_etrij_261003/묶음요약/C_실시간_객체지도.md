## 종합 — 이 묶음이 말하는 것 (2026-10-15 정리)

영상을 1배속으로 재생하며 ORB-SLAM3 지도 위에 물체를 올리는 **실시간 실험** 문서 일곱 개입니다. 한 장 평가(B 묶음)에서 "답을 덜 내는" 인식기가 실시간 지도에서는 **잘못 올라간 물체가 적고 결과가 안정적**이라는 것이 이 묶음의 결론이며, 논문 표 6(실시간 객체 지도 3회 반복)의 출처입니다.

**결론 네 줄**

1. **실제 영상에서 개선안 3 + 군집 먼저는 반복해도 8개 중 8개를 맞히고 잘못을 남기지 않습니다.** 4090 3회, 3080 Ti 3회, Blackwell 3회(7~8/8). 원본 0.5 는 6~8 사이에서 흔들리며 공룡 인형·사프란을 다른 자리로 올립니다.
2. **YCB-V 실시간에서는 오답 차이가 작습니다**(3회 평균 46.7 → 43.7, 폭 겹침). 인식 단계가 원본 판정 0.5 그대로이고, 장면에 없는 물체의 그럴듯한 자세가 검증을 통과하기 때문입니다. 오답 억제의 근거는 검증 켬/끔 대조(개선안 2 잘못 173 대 개선안 3 36~47)와 900장 · 실제 영상에서 가져옵니다(17 §2.3).
3. **인식 빈도는 GPU 와 함께 오르고 순위는 유지됩니다.** 개선안 3 계열 3080 Ti 2.8~3.5 Hz → 4090 6.2~7.5 Hz → Blackwell 6.8~8.0 Hz. GPU 가 빨라지면 처리 프레임이 늘어 YCB-V 의 잘못 올라간 항목도 함께 늘므로(27 서버·클라이언트 §2, F 묶음 27 §2), 실시간 점수는 같은 장비 안에서만 비교합니다.
4. **구성(한 대 · 두 대 · 네트워크 SLAM)은 결과를 바꾸지 않습니다.** ORB-SLAM3 는 CPU 작업이라 GPU 서버와 한 머신에 두어도 손해가 없습니다(27 §4).

**지표 정의**(05 §4.2, 13 §0): 찾은 객체 = 영상 끝 지도에 맞게 올라간 물체(YCB-V 는 ADD-S < 지름 10%, 실제 영상은 기준 위치 20 cm 안); 잘못 = 장면에 없는 물체 + 위치 틀림 + 중복; 오답률 = 잘못 / (맞음 + 잘못); 점수 = 맞음 / (장면 물체 + 잘못); 평균 점수 = 시간 축 전체 평균.

**관련 문서(다른 묶음):** 18 A(B 묶음) 실제 영상 4개 × 3회(4090, 개선안 3 평균 점수 49.5~90.6% 대 원본 35.0~68.3%); 26 §8(G 묶음) 08 세트의 4090 재현; 23 · 24(F 묶음) 실데이터 5녹화의 제안 방법 실행도 같은 실시간 체인입니다.

**주의:** 실제 영상의 기준 위치는 제안 방법의 이전 실행에서 가져온 것이라 독립 정답이 아닙니다(13 §0). ORB-SLAM3 가 1 m 를 넘는 잘못된 루프 보정을 넣은 실행은 버리고 다시 돌리는 규칙(15 §2, 22 §0)을 씁니다.
