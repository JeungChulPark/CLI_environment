3. 이 기술로 논문을 쓸 때의 강점과 보완점

강점

  1. 문제 정의가 분명하다. "SLAM과 인식을 나누면 실시간성은 지켜지지만 시계, 좌표계, 연산 지연, 통신 지연, 사후 보정이라는 다섯 가지 불일치가 생긴다"는 틀이 있고, 구성 요소마다 대응하는 문제가 정해져 있다. 심사위원이 따라가기 쉬운 구조다.
  2. 핵심 주장을 직접 증명하는 비교 실험이 있다. 같은 인식 결과 8,964건을 등록 방식 (a)~(d)로 다시 계산했다. 시각(도착→촬영), 저장 좌표(지도→키프레임), 키프레임 선택(도착 시각→촬영 시각)의 효과가 하나씩 분리된다(9.67 → 3.08 → 1.59 → 1.51 cm, 보정이 끼어든 경우 30.8 → 5.4 → 1.5%). 시스템 논문에서 흔치 않게 깔끔한 증거다.
  3. 실제 데이터의 규모가 크다. 실시간 실행 기록 113회, 같은 설정 반복 40회, 공개 데이터셋 두 개(YCB-V, YCB-M), 실제 주행 네 종류가 있어 수치를 통계로 제시할 수 있다.
  4. 범용성을 보여 준다. 영상 SLAM(ORB-SLAM3)과 LiDAR SLAM(HDL-Graph-SLAM) 두 방식에 같은 방법을 적용했다. SLAM의 추정은 바꾸지 않고 키프레임 정보만 내보낸다.
  5. 결과를 바꾸지 않는 SLAM 가속(24.7 → 15.4 ms, 정확도 동일)과 메타데이터 시각 문제(연관 타임스탬프가 −2.1~+3.8초 어긋남) 같은 실무 발견이 있다. 재현하려는 연구자에게 도움이 되는 내용이다.
  6. 한계를 수치로 밝힐 수 있다. 가려진 물체(46% 대 3%)와 잘못된 루프 보정(40회 중 2회)을 숨기지 않고 적으면 심사에서 신뢰를 얻는다.

3. 권장 순서

  1. 새 녹화 없이 할 수 있는 실험을 먼저 한다. E2(지연 곡선), E5(통계), E3(한 장치 대 두 장치), E6(LiDAR 판)은 기존 기록과 도구로 할 수 있고, 원고의 약점을 가장 많이 메운다.
  2. E4(같은 GPU 비교)는 공개 코드를 설치해야 하지만 새 녹화가 필요 없다.
  3. E1(AprilTag 정답 주행)은 준비(인쇄·측량)가 필요하다. 논문의 신뢰도를 가장 크게 올리므로 IROS 마감(2027년 3월) 전에 끝내는 것을 목표로 한다.
  4. E7~E10은 E1 녹화 때 함께 기록한다.

주의: E3의 "한 장치" 실행은 논문의 비교 기준(baseline)으로만 쓴다. 특허 문서에는 넣지 않는다 (특허는 두 장치 분리를 전제로 한다).

특허 쪽에서 할 일

  1. CLON과 DSP-SLAM++를 변리사에게 추가로 전달한다. 둘 다 2026년에 공개되어 출원보다 앞선다.
  2. CLON: 텍스트 프롬프트 후보 생성과 겹친다.
  3. DSP-SLAM++: 비동기 객체 처리와 시점 자세 묶기가 겹친다.
  4. 차이를 명세서에 분명히 적는다. 본 발명이 두 문헌과 다른 점은 다음과 같다.
  5. 촬영 시각의 기준 키프레임과 함께 키프레임 목록을 다시 보낸다.
  6. 다른 장치에서 SLAM 자세가 늦게 올 때 기다렸다가 등록한다.
  7. 색조·채도 분포 관문과 '없음' 출력을 갖춘 순차 관문을 쓴다.
  8. Rivian 특허는 변리사가 관련성을 판단한다. 늦게 온 측정을 시간순으로 다시 넣는 일반 기술이다.

1. SAM-6D 원논문은 어떻게 비교했나

1.1 평가 틀

항목 SAM-6D 가 쓴 방식

2. 우리가 내세울 것 — 자세 추정 논문이 아니라는 점

2.1 질문이 다르다

SAM-6D 류 (벤치마크 자세 추정) 우리 (객체 지도용 인식)
묻는 것 물체마다 얼마나 정확한 자세를 내나 (AR) 지도에 틀린 물체를 남기지 않으면서 쓸 만한 재현율과 실시간 처리율을 유지하나
출력 물체마다 반드시 답 하나 (장면에 없어도 1위를 냄) 통과 가설이 없으면 답하지 않음(abstention)
오답 비용 없음 (재현율 지표만) 큼 — 틀린 항목은 지도에 남아 계획을 망침
시간 장당 1.4~4.4 s 도 허용 영상 처리율(Hz)·지도 올라가는 시간
평가 단위 한 장 한 장 + 영상 끝 지도 상태(맞음/잘못/못 찾음)

2.2 내세울 점 네 가지 (모두 수치 있음)

  1. 가설 집합 검증과 기권. PEM 가설 300개를 기하 1위로 뭉개지 않고 윤곽·무늬·합의로 채택 여부를 정한다. 학습 없음, 가중치 변경 없음, 입력은 원본과 같음(CAD 만). 900장: 오답/장 0.308 → 0.051(1/6), 정답 비율 93.2 → 98.6%.
  2. 같은 물체끼리는 자세가 더 정확하다. 두 방법이 모두 답한 3,378개에서 ADD-S AUC 94.6 → 96.7, 오차 중앙값 1.79 → 1.73 mm. "답을 빼서 정밀도를 산 것" 이 아니라 "남긴 답도 더 좋다" 는 근거.
  3. 군집 먼저 검증으로 비용을 줄여 실시간에 들어간다. 답 99% 동일, 장당 342 → 240 ms(원본 530 의 45%), 실시간 처리율 2배(260901 3.63 → 7.54 Hz, YCB-V 1.76 → 3.14 Hz).
  4. 지도 결과가 안정적이다. 실제 영상 260901 3회 모두 최종 지도 8/0, 원본은 6/3·6/3·8/1.

2.3 미리 인정할 것 (표에 함께 둔다)

  • 찾은 비율 92.4 → 80.9%(−11.5%p), BOP AR 82.8 → 74.1. 둘 다 재현율 지표라 기권의 직접 비용이다. 검증이 버린 414개 중 249개는 맞는 답이었다(16 문서).
  • YCB-V 실시간에서 원본 대비 잘못 항목 차이는 작다(3회 평균 46.7 → 43.7, 폭 겹침). 오답 억제 근거는 검증 켬/끔 대조(173 → 36~47)와 900장, 실제 영상에서 가져온다.
  • 속도 이득의 절반은 ViT-L → ViT-S 교체(개선안 2 단계, 181 → 29 ms)에서 온다. 검증 자체는 비용이고, 군집 먼저는 그 비용을 줄인 것이다.
