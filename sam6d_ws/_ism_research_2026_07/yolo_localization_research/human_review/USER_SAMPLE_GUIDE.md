# 복구 사례 표본 검수 (30건, 약 5분)

## 무엇을 묻는가

각 화면에 상자 3개가 있습니다.

| 색 | 의미 |
|---|---|
| **초록** | 새 설정(주로 YOLOE)이 만든 **복구 박스** ← 판정 대상 |
| 주황 | **기대 위치** — 인접 프레임에서 가져온 **근사** (정답 아님) |
| 빨강 | 현행이 그 객체 후보로 만든 박스 (없을 수 있음) |

> **초록 상자 안에 상단의 `TARGET =` 객체가 실제로 있습니까?**

주황은 참고용입니다. 근사라 어긋나 있을 수 있으니 **초록만 보고 판정**해 주십시오.

## 선택지

| 키 | 값 | 언제 |
|---|---|---|
| `1` | `correct` | target 객체가 초록 상자 안에 잘 들어 있음 |
| `2` | `partial` | 일부만 들어 있거나 상자가 어긋났지만 그 객체는 맞음 |
| `W` | `wrong_object` | 초록 상자에 **다른 물건**이 있음 |
| `B` | `background` | 초록 상자가 **배경만** 잡음 |
| `U` | `unsure` | 판단 불가 |

## 실행

```bash
cd sam6d_ws/_ism_research_2026_07/yolo_localization_research/human_review
python3 serve_sample.py
```

접속: `http://127.0.0.1:8765` (안 되면 `http://10.254.176.41:8765`)

`Space` 다음 · `←` 이전. 클릭 즉시 CSV 저장.

## 왜 30건인가

254건은 설정 간 중복이었고 **고유 사례는 34건**입니다. 30건이면 사실상 전수입니다.

## 이 검수로 확정되는 것

`correct + partial` 비율이 곧 **복구율 0.362의 실제 신뢰도**입니다.
50% 미만이면 인접 프레임 기대 위치가 부정확하다는 뜻이므로 권장안을 재검토해야 합니다.
