전체 흐름

세 번의 걸러냄, 서로 다른 세 가지 질문

같은 후보 집합을 세 번 거르지만, 각 단계가 던지는 질문은 전혀 다르다. A는 “이 3쌍의 대응이 서로 앞뒤가 맞나”를 묻고(대응끼리의 자기모순 검사), B는 “관측한 점들이 물체 표면 위에 얹히나”를 묻고(형상 정합), C는 “거기에 있어야 할 무늬가 실제로 거기 있나”를 묻는다(외형 정합). A와 B는 둘 다 기하지만 재는 대상이 다르고 — A는 대응 3개, B는 관측점 전부 — C만이 유일하게 RGB를 본다.

6000
단계 0 · 가설 생성

포즈 하나는 대응 3쌍에서 태어난다

coarse 트랜스포머가 내놓는 것은 포즈가 아니라 대응 점수 행렬 하나다. 관측 희소점 196개와 모델 희소점 196개 사이의 어텐션에 행·열 양방향 softmax를 곱해 196 × 196 = 38,416칸짜리 확률판을 만들고, 배경 토큰에 붙은 점은 0으로 지운다. 그 다음 ** 1.5 로 분포를 뾰족하게 만든다 — 확신 있는 칸을 더 자주 뽑겠다는 뜻이다.

여기서 18,000번을 추첨한다. 누적분포에 난수를 던져(searchsorted) 칸 하나를 고르는 일을 18,000번 반복하고, 그것을 3개씩 묶어 6000개의 삼중 대응을 만든다. 3쌍이면 강체 변환이 유일하게 결정되므로, 묶음 하나가 곧 포즈 후보 하나다.

utils/model_utils.py:259 — 샘플링과 3점 SVD
cumsum_weights = torch.cumsum(pred_score, dim=1)          # [B, 196*196]
cumsum_weights /= cumsum_weights[:, -1].unsqueeze(1) + 1e-8
idx = torch.searchsorted(cumsum_weights, torch.rand(B, n_proposal1*3))
idx1, idx2 = idx.div(N2, rounding_mode='floor'), idx % N2   # 칸 → (관측 i, 모델 j)

p1 = torch.gather(pts1, 1, idx1).reshape(B*6000, 3, 3)   # 관측 3점
p2 = torch.gather(pts2, 1, idx2).reshape(B*6000, 3, 3)   # 모델 3점
pred_rs, pred_ts = WSVD(p2, p1, None)                       # 3점 Procrustes
6000 → 300
단계 A · 3점 잔차 필터

잔차가 묻는 것은 “두 삼각형이 합동인가”다

여기가 가장 오해하기 쉬운 지점이다. 3점으로 푼 변환을 그 3점에 다시 적용해 오차를 잰다니, 정의상 0이 나와야 할 것 같다. 실제로 대응이 옳으면 0에 가깝게 나온다. 핵심은 틀렸을 때다.

SVD가 하는 일은 “관측점 삼각형”과 “모델점 삼각형”을 최대한 포개는 것이다. 강체변환은 삼각형의 모양을 바꾸지 못한다 — 돌리고 옮길 뿐이다. 그러니 세 대응 중 하나라도 엉뚱한 모델점을 가리키면 두 삼각형의 변 길이가 달라지고, 아무리 잘 포개도 남는 오차가 생긴다. 이 남는 양이 잔차다.

즉 이 필터는 관측을 얼마나 잘 설명하는지를 재지 않는다. 뽑아 온 대응 3쌍이 자기들끼리 앞뒤가 맞는지만 본다. 데이터 전체와의 대조는 다음 단계의 몫이다.

utils/model_utils.py:275 — 잔차 계산과 상위 300 선택
p1 = p1.reshape(B, 6000, 3, 3)      # 관측 3점
p2 = p2.reshape(B, 6000, 3, 3)      # 모델 3점
dis = torch.norm((p1 - pred_ts) @ pred_rs - p2, dim=3).mean(2)   # [B, 6000]
idx = torch.topk(dis, 300, dim=1, largest=False)[1]                # 작을수록 좋다
왜 이 필터만으로는 부족한가 잔차는 뽑아 온 3점 안에서만 계산된다. 그래서 통과했다는 것이 “관측 전체를 설명한다”는 뜻이 전혀 아니다. 극단적으로, 추첨이 같은 칸을 세 번 뽑으면 삼각형이 한 점으로 찌그러져 잔차가 정확히 0이 나오고 — 완벽한 점수로 통과하지만 포즈는 쓰레기다. 확률은 낮지만 구조상 막혀 있지 않다. 그런 후보를 걷어내는 것이 다음 단계다.

단계 B · 기하 점수

이제 관측점 전부를 모델 표면에 대본다

살아남은 300개 각각에 대해, 후보 포즈로 관측 희소점 196개 전부를 물체 좌표계로 옮긴다. 그리고 옮겨진 점마다 모델점 1024개 중 가장 가까운 것까지의 거리를 잰다. 점수는 그 거리들의 역수 — 사실상 1 / 평균 최근접거리다. 배경으로 분류된 관측점은 가중치 0으로 빠진다.

이 점수는 표면에서 얼마나 떠 있는가만 잰다. 그것이 강점이자 결정적 약점이다. 상자처럼 앞뒤가 비슷한 물체에서는 180° 뒤집힌 후보도 관측된 깊이를 똑같이 잘 설명한다. 두 후보가 사실상 동점이 되고, 무작위 추첨으로 태어난 순서가 승자를 정한다 — 프레임마다 물체가 홱 뒤집히는 현상의 직접적인 기전이다.

transformed_pts = (pts1.unsqueeze(1) - pred_ts) @ pred_rs   # 관측 196점을 후보 300개로 각각 이동
dis = torch.sqrt(pairwise_distance(transformed_pts, expand_model_pts))
dis = dis.min(2)[0].reshape(B, 300, -1)                     # 모델 1024점 중 최근접
scores = weights1.sum(2) / ((dis * weights1).sum(2) + 1e-8)     # = 1 / 평균 최근접거리

단계 C · 텍스처 점수 기본 OFF

같은 자리에 있어야 할 무늬가 실제로 있는가

기하가 못 가르는 축을 외형으로 가른다. 쓰는 재료는 PEM이 이미 계산해 둔 특징이다 — DINOv2가 아니라 PEM 자체의 MAE 사전학습 ViT-base가 뽑은 256차원 픽셀 특징이다. 관측 크롭에서 나온 dense_fm과, 템플릿 42뷰에서 미리 뽑아 .pt로 저장해 둔 dense_fo가 같은 인코더·같은 공간에 있기 때문에 코사인이 의미를 갖는다.

결정적으로, 특징은 포즈가 아니라 점에 붙어 있다. 후보가 바뀌어도 특징을 다시 뽑지 않는다 — 후보는 어느 관측점이 어느 모델점과 짝이 되는지만 바꾼다. 그래서 후보 50개를 재정렬해도 ViT 순전파는 0회이고, 비용이 사실상 0이다.

utils/model_utils.py:212 — 후보별 짝짓기와 코사인
order = torch.argsort(geo_scores, descending=True)[:, :topk]   # 기하 상위 50개만
pm = appe['dense_pm'][b][::stride]        # 관측 2048 → 512점 (결정적 표본)
fm = normalize(appe['dense_fm'][b][::stride]) # 관측 특징 [512, 256]
po, fo = appe['dense_po'][b], normalize(appe['dense_fo'][b])  # 템플릿 [2048, 256]

obj = torch.einsum('kji,knj->kni', R, pm.unsqueeze(0) - t)     # ← 후보가 개입하는 유일한 지점
nn  = torch.cdist(obj, po).argmin(2)                           # 최근접 모델점
s_appe = torch.einsum('nd,knd->kn', fm, fo[nn]).mean(1)       # [50] 코사인 평균
특징의 출처 dense_fo는 템플릿 42뷰 × 5000점을 이어 붙인 뒤 FPS로 2048점을 추린 것이다. 실시간 노드는 이것을 객체별 .pt(tp, tf)로 미리 만들어 두고 로드만 하므로, 런타임에 템플릿 ViT 순전파는 0회다. ISM의 DINOv2 특징은 이 경로 어디에도 들어오지 않는다 — ISM이 넘기는 것은 마스크와 점수뿐이다.

단계 D · 결합

두 점수를 z-정규화해서 더한다

기하 점수는 1/거리라 단위도 범위도 제멋대로고, 코사인은 0~1이다. 그대로 더할 수 없으니 상위 50개 안에서만 각각 z-score로 바꾼 뒤 z(외형) + w_geo · z(기하)의 최댓값을 고른다. 정규화 모집단이 “전체 300개”가 아니라 “살아남은 50개”라는 점이 중요하다 — 이미 기하로 걸러진 집단 안에서의 상대 비교다.
